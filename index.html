線 = 計算 (PGA 緑・LPGA ピンク・自分は青で 1 球 1 本・橙の点線は確認が要る球)◆ ▲ ○ = 測ったキャリー (TrackMan の平均 / X-SWING の画面)横棒 = 測った最高点細いまっすぐな線 = 打ち出しの向き (横から見た打出角・軌跡がこの線より上 = 揚力が重力より強い間に上へ曲がった)紫 = 変えた後 (計算・点線にしない・確認が要る球だけ今と同じ点線・打ち出しの向きの線も変えた後の打出角から)
  • 同じように振れたと仮定した計算 (長さ・握る位置・反発は同じ)・実施した変更ではない。
  • スピンは衝突の比で変える・打出角はそのまま (近似)。ヘッドの質量が変わると法線と接線の比が違うので、本当は打出角も少し動く (逆算 → 前向きとの差は小さいが、足す重さが大きいほど大きくなる)。MacKenzie 2015 のドライバーの実験では、重いヘッドで動的ロフトとスピンが増えた (当たり方の変化は入れていない)。
  • 人は計算どおりに反応しない (Haeufle 2012: シャフト +22 g で 12 人中 10 人は差が検出されなかった)。
  • ヘッドに付けた時のボールスピードとスピンの補正は、法線方向・接線方向の衝突の式による近似 (Penner 2001)。シャフト・グリップに付けた時は衝突への寄与を 0 とする簡略化。
  • MOI は部品モデルの推定 I_est (一様なシャフト・ヘッド自身の慣性は無視)。m·B² より大きいのはシャフトとグリップの項を足したため。
  • カタログの参考値から計算した見積もり・買った・替えた記録ではない。候補の仕様はカタログの参考値 (候補の表) で、実測とはずれることがある。全部の欄を手で書き換えられる。
  • 土台との条件の近さは、自分の記録 (土台の番手) とロフト・長さがどれだけ近いかの目安で、当てはまりの保証ではない (カタログの値の確かさとは別)。
  • θ・e・p・δ は当てはめの値 (この式に当てはめた値)。本物のスピンロフト・反発係数・入射角ではなく、δ も動的ロフトそのものではない (静的ロフトからの補正角)。転がりのモデルのずれ・ヘッド質量の誤差・計測誤差を吸い込む。
  • 候補にも土台の e をそのまま使っている (e の持ち越し)。クラブが変わっても同じとは限らない (Penner 2001 も e を衝突速度に依存させている)。逆算には記録の HS がそのまま入る。
  • 計算モデルの詳細のツアーの答え合わせ (ツアー平均の 5W から 3W・Driver を予測) では打出角が低く出た。キャリーは 2D 弾道による参考の差 (計算 − 計算)。
  • バランス点は SW の差から出した、土台のずれを持ち越した推定 (記載と実測の差が候補にも共通するとは限らない)。
  • 振りを変えた線は、当てはめた当たり方のまま、HS だけ変えた仮定の軌跡 (PGA 選手の球になるわけではない・速さで当たり方が変わることは入れていない)。
  • 「そろえる」は球ごとの HS をその番手のツアー平均 (TrackMan 2023 の外部の平均・自分の記録ではない) にする。HS の式の比を掛けない。使わないます (表 → で選ぶ) の値は計算に渡さない。
  • HS は 2 つの式で見積もった: HS' / HS = (R + L') / (R + L) × (X / X')^n (腕 + クラブの比較式 × クラブの MOI の補正 (経験)・R = 肩から手首・L = クラブの長さ・重さを足す時は長さが同じなので MOI の補正だけ)。X = グリップ端の MOI (中心) か、肩まわりの MOI (腕 + クラブ・腕の質量と慣性は Lampsa 1975 の仮定)。指数 n はグリップ端の MOI に当てはめた値で、肩まわりに使うのは転用。二重振り子から導いた理論式ではなく、2 つの式が本当の値を挟む保証もない。替える時は 3W もウェッジも、クラブの種類・長さの領域をまたぐ転用。
  • 幅は選んだ HS の式 (グリップ端 / 肩まわりの MOI) と n (0.19〜0.28) の感度 (シャフト重量が未確定の番手は仮定 2 通りも) で、実際の誤差の範囲ではない。e の移植・摩擦・打点・打ち方・弾道モデルの誤差を含まない。
  • そろえる時は HS を直接決めるので、HS の式の幅を流用しない (幅なし)。
  • 幅が無いのは不確かさがゼロという意味ではない (x% は倍率 1 つ・そろえる時は HS を直接決めるので、HS の式の感度の幅が無いだけ)。
  • 計算の一致 (自己点検・変えない時の差 0) は予測が確かという意味ではない。キャリーの差は「計算 − 計算」だけで、画面のキャリーに差を足した値ではない。
