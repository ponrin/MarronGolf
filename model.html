1. ボールにかかる力

  • 重力: 真下に mg。
  • 空気抵抗 Fd: 進む向きと逆。速さの 2 乗に比例し、強さは係数 Cd で決まる。
  • 揚力 Fl: 進む向きに直角。バックスピンの時は上向きで、球を持ち上げる (マグヌス効果)。強さは係数 Cl。
  • Cd と Cl はスピンの強さ Sp (球の表面の回る速さ ÷ 進む速さ) で変わる。
  • スピンは飛んでいる間に少しずつ減る。
  • 横から見た 2D の計算で、左右の曲がり (サイドスピン)・風・地面の跳ねと転がりは入れていない。

2. 式

状態 = 位置 (x, y)・速度 (vx, vy)・スピン ω [rad/s]。v = √(vx² + vy²)、A = π r² (ボールの断面積)
打ち出し: x = y = 0、vx = v₀ cos(打出角)、vy = v₀ sin(打出角)、ω = スピン [rpm] × 2π / 60。 y が 0 より下になった刻みで、前の刻みとの間を直線でつないで着地点を出す (キャリー・飛んでいた時間・落下角)。最高点は刻みごとの y の最大。
q = ½ ρ A v² (動圧 × 面積 [N]) ax = q (−Cd·vx − Cl·vy) / (m v) (抵抗は速度と逆・揚力は速度に直角) ay = q (−Cd·vy + Cl·vx) / (m v) − g dω/dt = −k ω (スピンの減り方)

7. HS とボールスピードの式

Jorgensen 1970 などの原典は読めず、同じ式を本文で書いている Cross 2005・Sharp 2009 などで確かめた。 どの式も「同じように振れたら」の計算で、クラブの仕様だけでは HS の高さは決まらない (人ごとの係数が要る)。

7-1. 二重振り子

Cross 2005 の式 5 (Lagrange から導いて確認)。原型は Williams 1967、Cochran & Stobbs 1968・Jorgensen 1970 も同じ形。
A = I1 + M2 L1² B = M2 h2 L1 I2 = I_cm + M2 h2² （h2 = 手首からクラブの重心・I2 = 手首まわりのクラブの MOI） 腕: A θ̈1 + B cosΔ θ̈2 − B sinΔ θ̇2² = τ1 − τ2 クラブ: I2 θ̈2 + B cosΔ θ̈1 + B sinΔ θ̇1² = τ2 (Δ = θ2 − θ1) ヘッドの速さ (一直線の時) v = L1 θ̇1 + L_h θ̇2
自然リリース (手首に力を入れずにほどける所・静止から・ハブのトルク一定): θ_rel = (I2 + B cos δ) / (2 B sin δ) トルクが時間に比例する時は 4/3 倍 δ = 90° なら θ_rel = I2 / (2 L1 M2 h2) → 短いクラブほど早くほどける

7-2. 重さと長さ → HS

注意: 二重振り子では重さを変えるとほどけ方や腕とクラブのエネルギーの分け方も変わるので、n = 1/2 は上限ではない。 グリップ端を中心に回すと置く式 (HS ∝ L・HS ∝ L^(1 − 2n)・式 M) は、肩を中心に腕ごと回る半径 (腕の分) を無視するので理論式として使わない (外した — 長さの扱いの話で、下の MOI の補正とは別)。 F_X は二重振り子から導いた理論式ではない (角速度の比やリリースは解いていない)。指数 n ≈ 0.25〜0.26 はクラブのグリップ端まわりの MOI に当てはめた値で、肩まわりの J に使うのは転用。
HS = C / I^n (I = グリップ端まわりの MOI・C = 人ごとの係数) — Cross & Nathan 2009

7-4. HS → ボールスピード · ヘッドの重さ

v_n = (1 + e) HS cos θ / (1 + m/M) v_p = HS sin θ / (3.5 + m/M) スピン = 2.5 v_p / r (m = ボール・M = ヘッド・θ = スピンロフト・e = 反発係数) — Penner 2001 HS = C M^−n_M (Daish 1972 は n_M = 1/5.3) と掛けて一番速い M: M_opt = m (1/n_M − 1)

8. 確かめたこと・確かめていないこと

確かめたこと (計算の作りの検査)
  • 空気が無ければ (ρ = 0) きれいな放物線になり、解析解と一致 (テスト)
  • 刻みを半分にしてもキャリーがほぼ変わらない (収束・テスト)
  • 画面の JavaScript の計算と Python の計算が相対 1e-9 で一致 (テスト・画面を開くたびの自己点検)
  • 式・単位・力の向きを読んで検算
確かめていないこと
  • 屋外で着地点を測った値との一致 (X-SWING の画面の値も、屋外の独立した測定ではない)
  • 落下角 (上の答え合わせでは計算がいつも浅い)・止まりやすさ
  • ボールの銘柄・気温・標高の違い (空気密度は海面・15℃の 1.225 kg/m³ で固定)
  • サイドスピン・風・地面の跳ねと転がり (トータルは計算しない)
  • ρ = 0 → 放物線
  • 刻み半分 → 収束
